# 从程序员到初级架构师：政策库抓取系统（分章节教材）

本教材用于带新手从“能写脚本”走向“能设计可运行的抓取系统”。每章都包含：
- **读代码入口**：先看哪些文件/函数
- **你要学会的架构能力**：从代码里抽象出来的能力点
- **常见坑**：新手最容易踩的坑与排查方式
- **练习**：能动手验证的任务

## 建议阅读方式（强烈推荐）
- **先跑起来**：用 `python -m crawler.main list/detail` 跑出数据库与 raw_html。
- **再看数据流**：从 `crawler/main.py` 进入，跟到 `tasks/*_task.py` → `fetcher.py` → `parser/*` → `storage/*`。
- **最后看边界**：重试/限速/失败/幂等写入/质量阈值（这才是系统能不能稳定跑的关键）。
